# Улучшения UX: Видимость пароля и автопоиск портов

## Дата: 2026-10-05

## Обзор изменений

Добавлены два улучшения пользовательского интерфейса для упрощения настройки камер:
1. Кнопка показа/скрытия пароля в поле ввода пароля

## 1. Показ/скрытие пароля

### Проблема
В форме редактирования камеры пароль всегда был скрыт звездочками, что затрудняло проверку правильности ввода.

### Решение
Добавлена иконка "глаз" справа от поля пароля, позволяющая переключать видимость пароля.

### Реализация

**Файл**: `app/src/main/java/com/example/denmediaipcams/ui/components/CameraEditDialog.kt`

**Добавленные импорты**:
```kotlin

import androidx.compose.ui.text.input.VisualTransformation
```

**Изменения в поле пароля**:
```kotlin
var passwordVisible by remember { mutableStateOf(false) }
OutlinedTextField(
    value = password,

    label = { Text("Пароль") },
```

### Поведение
- По умолчанию пароль скрыт (иконка "глаз закрыт")
- При нажатии на иконку пароль становится видимым (иконка "глаз открыт")
- Повторное нажатие снова скрывает пароль
- Состояние сбрасывается при закрытии диалога

## 2. Автопоиск портов камеры

### Проблема
При добавлении камеры пользователю приходилось вручную угадывать и проверять порты, что занимало много времени.

### Решение
Добавлена кнопка "Найти доступные порты" на вкладке "Порты", которая автоматически:
1. Сканирует стандартные порты IP-камер
2. Определяет тип порта (RTSP, HTTP, ONVIF)
3. Автоматически заполняет пустые поля найденными портами
4. Проверяет доступность найденных портов

### Реализация

**Проверяемые порты**:
- **554** - RTSP (стандартный порт для видеопотока)
- **80** - HTTP (веб-интерфейс камеры)
- **8080** - HTTP/ONVIF (альтернативный HTTP или ONVIF)
- **81** - HTTP (альтернативный)
- **8000** - ONVIF (альтернативный)

**Алгоритм работы**:
```kotlin
fun autoFindPorts() {
    // 1. Проверка наличия IP адреса
    if (ipAddress.isBlank()) {
        Toast.makeText(context, "Сначала укажите IP-адрес камеры", Toast.LENGTH_SHORT).show()
        return
    }
    
    // 2. Сканирование портов с таймаутом 1 секунда на порт
    val portsToCheck = listOf(
        554 to "RTSP",
        80 to "HTTP",
        8080 to "HTTP/ONVIF",
        81 to "HTTP",
        8000 to "ONVIF"
    )
    
    // 3. Проверка каждого порта
    for ((port, type) in portsToCheck) {
        val result = NetworkTester.pingPort(ipAddress, port, timeoutMs = 1000)
        if (result is PortPingStatus.Success) {
            // 4. Определение типа и заполнение только пустых полей
            when {
                type == "RTSP" && rtspPortStr.isBlank() -> 
                    foundPorts["RTSP"] = port
                    
                type.contains("HTTP") && !type.contains("ONVIF") && httpPortStr.isBlank() -> 
                    foundPorts["HTTP"] = port
                    
                type.contains("ONVIF") && onvifPortStr.isBlank() -> 
                    foundPorts["ONVIF"] = port
            }
        }
    }
    
    // 5. Заполнение найденных портов в поля
    foundPorts["RTSP"]?.let { rtspPortStr = it.toString() }
    foundPorts["HTTP"]?.let { httpPortStr = it.toString() }
    foundPorts["ONVIF"]?.let { onvifPortStr = it.toString() }
    
    // 6. Автоматическая проверка найденных портов
    foundPorts.forEach { (type, port) ->
        pingSinglePort(type, port.toString(), defaultPort, showToast = false)
    }
}
```

### Особенности работы
- ✅ Кнопка активна только если указан IP адрес
- ✅ Показывает прогресс сканирования с указанием текущего проверяемого порта
- ✅ Заполняет только **пустые** поля - не перезаписывает существующие значения
- ✅ Выбирает первый найденный порт для каждого типа
- ✅ После заполнения автоматически проверяет доступность портов
- ✅ Показывает уведомление со списком найденных портов
- ✅ Быстрое сканирование - таймаут 1 секунда на порт (всего ~5 секунд)

### Пример работы

**Сценарий 1: Все порты стандартные**
```
IP: 192.168.1.100
Результат: RTSP: 554, HTTP: 80, ONVIF: 8080
```

**Сценарий 2: Нестандартные порты**
```

Найдено: RTSP: 554, HTTP: 8080
Не найдено: Порт 80 (недоступен)
```

**Сценарий 3: Частично заполненные поля**
```
До сканирования: RTSP: 554, HTTP: (пусто), ONVIF: (пусто)
После сканирования: RTSP: 554 (не изменен), HTTP: 80, ONVIF: 8080
```

✅ Умное заполнение - не перезаписывает существующие значения

## Ограничения

### Автопоиск портов
- Проверяет только стандартные порты камер
- Не проверяет произвольные порты
- Таймаут 1 секунда может быть недостаточен для медленных сетей
- Определение типа порта основано на стандартах, может быть неточным
