# Changelog

## [Неверсионированные изменения] - 2026-10-05

### Добавлено

#### Запись, расписание и детекция движения в самой камере
- На вкладке «Архив видео» диалога камеры — блок «Запись и детекция движения» (Dahua, Hipcam, XMEye/DVRIP):
  режим записи (не записывать / постоянно / по движению / по расписанию), недельное расписание, предзапись,
  перезапись при заполнении карты, детекция движения (чувствительность, зоны сеткой) и детекция людей
- Зоны детекции выбираются поверх последнего кадра камеры (сначала превью из списка, затем свежий снимок Dahua/Hipcam
  или кадр потока): выбранные ячейки видны как есть, остальные затемнены; есть кнопка «Обновить кадр»
- Настройки читаются из камеры и записываются в неё кнопкой «Применить к камере» с проверкой чтением обратно;
  если камера не подтвердила, прежние настройки возвращаются

#### Поворот видео средствами камеры
- Поворот на 180° теперь выполняет сама камера (переворот и отражение в её настройках), если она это умеет:
  Dahua (VideoImageControl), Hipcam (setimageattr), XMEye/DVRIP (PictureFlip/PictureMirror, при включённом протоколе)
- Поворот на 90° делает камера только при поддержке Rotate90 (Dahua); в остальных случаях — программно, как раньше
- Положение камеры «без поворота» запоминается, поэтому уже перевёрнутая в настройках камера не переворачивается назад
- Если камера не ответила или не приняла настройку, видео поворачивается программно

#### UX улучшения
- **Показ/скрытие пароля**: Добавлена иконка "глаз" в поле пароля для переключения видимости
  - По умолчанию пароль скрыт
  - Клик по иконке показывает/скрывает пароль
  - Помогает избежать ошибок при вводе сложных паролей

- **Автопоиск портов камеры**: Добавлена кнопка "Найти доступные порты" на вкладке "Порты"
  - Автоматически сканирует стандартные порты камер (554, 80, 8080, 81, 8000)
  - Определяет тип порта (RTSP, HTTP, ONVIF)
  - Заполняет только пустые поля портов
  - Автоматически проверяет доступность найденных портов
  - Показывает прогресс сканирования с текущим проверяемым портом
  - Быстрое сканирование (~5 секунд на всю проверку)

- **Кнопка удаления камеры в форме редактирования**
  - Добавлена кнопка "Удалить" красного цвета в диалоге редактирования камеры
  - Кнопка отображается только при редактировании существующей камеры (не при добавлении новой)
  - Добавлен диалог подтверждения удаления с названием камеры
  - Удаление происходит только после явного подтверждения пользователем

### Исправлено

- **XMEye/DVRIP: одна SD-карта показывалась как две.** Камера делит карту на раздел записей и раздел снимков
  (один диск, два раздела); теперь разделы диска сводятся в одну карту (объём и занятое место суммируются,
  форматирование нацелено на раздел записей)

#### Критическое
- **Краш при подключении к камерам без HTTP порта**: Исправлен краш приложения при подключении к камерам без доступного HTTP порта (порт 80)
  - Теперь приложение корректно обрабатывает камеры с доступными только RTSP и PTZ портами
  - Добавлена обработка исключений `ConnectException`, `SocketTimeoutException`, `UnknownHostException`
  - HTTP запросы теперь возвращают ошибку (код 0 или null) вместо краша приложения

#### Управление фокусом камеры
- **Автоматический возврат фокуса**: Исправлена проблема, когда после изменения фокуса камера автоматически возвращала его обратно
  - Добавлена задержка после переключения в ручной режим фокусировки для корректного применения изменений
  - Камера теперь сохраняет установленный фокус без нежелательного возврата
  
- **Медленное изменение фокуса**: Увеличена скорость изменения фокуса ползунком
  - Шаг фокуса увеличен в 2.5 раза (0.04 → 0.10)
  - Интервал между шагами уменьшен на 40% (250мс → 150мс)
  - Общая скорость изменения фокуса увеличена примерно в 4 раза (полный диапазон за ~5-6 секунд вместо ~12 секунд)

### Добавлено
- **Кнопка удаления камеры в форме редактирования**
  - Добавлена кнопка "Удалить" красного цвета в диалоге редактирования камеры
  - Кнопка отображается только при редактировании существующей камеры (не при добавлении новой)
  - Добавлен диалог подтверждения удаления с названием камеры
  - Удаление происходит только после явного подтверждения пользователем

### Технические изменения

#### CameraHttp.kt
- Улучшена обработка ошибок в методе `send()` с явным преобразованием сетевых исключений в `IOException`
- Метод `request()` теперь перехватывает `IOException` и возвращает `Response(0, ...)` при сетевых ошибках
- Метод `requestBytes()` теперь перехватывает `IOException` и возвращает `null` при сетевых ошибках
- Добавлен `finally` блок для гарантированного отключения HTTP соединения

#### PtzController.kt
- Исправлена логика пошагового фокуса в методе `startRelativeFocus()`
- Обновлены константы `RELATIVE_FOCUS_STEP` и `FOCUS_STEP_INTERVAL_MS` для более быстрого изменения фокуса

#### CameraEditDialog.kt
- Добавлен опциональный параметр `onDelete: ((String) -> Unit)? = null`
- Добавлена кнопка удаления в `dismissButton` секции диалога
- Добавлен диалог подтверждения удаления с предупреждением о необратимости действия
- Добавлена переменная состояния `showDeleteConfirmation`

#### MainActivity.kt
- Добавлен обработчик `onDelete` в вызов `CameraEditDialog`
- Подключен метод `viewModel.deleteCamera()` к кнопке удаления

### Детали реализации

#### HTTP ошибки
Все существующие вызовы `CameraHttp` уже были обернуты в try-catch блоки, поэтому изменения обратно совместимы:
- `PtzController.kt` - PTZ команды через HTTP API
- `OnvifClient.kt` - ONVIF SOAP запросы
- `NetworkTester.kt` - проверка авторизации и портов
- `PtzProtocolDetector.kt` - автоопределение протокола PTZ
- `CameraFrameGrabber.kt` - захват кадров через HTTP
