## 1. Исправление краша при недоступном HTTP порте

### Проблема
Приложение вылетало при попытке подключения к камерам, у которых доступны только RTSP и PTZ порты, но HTTP порт (80) недоступен.

### Решение
- Добавлена обработка сетевых исключений в `CameraHttp.kt`
- Методы `request()` и `requestBytes()` теперь возвращают ошибку вместо краша
- HTTP порт стал опциональным - камеры могут работать только с RTSP

### Файлы
- `app/src/main/java/com/example/denmediaipcams/network/CameraHttp.kt`

---

## 2. Исправление проблем с фокусом камеры

### Проблема 1: Автоматический возврат фокуса
После изменения фокуса с помощью ползунка камера автоматически возвращала его обратно.

### Решение
Добавлена задержка после переключения камеры в ручной режим фокусировки, чтобы изменения корректно применились.

### Проблема 2: Медленное изменение фокуса
Ползунок фокуса слишком медленно изменял фокус камеры.

### Решение
- Увеличен шаг фокуса: `0.04 → 0.10` (в 2.5 раза)
- Уменьшен интервал между шагами: `250мс → 150мс` (на 40%)
- **Результат**: Скорость изменения фокуса увеличена в ~4 раза

### Файлы
- `app/src/main/java/com/example/denmediaipcams/network/PtzController.kt`

## 3. Добавление кнопки удаления камеры

### Проблема
В форме редактирования камеры отсутствовала возможность удаления камеры.

### Решение
- Добавлена красная кнопка "Удалить" в диалог редактирования
- Кнопка показывается только при редактировании существующей камеры
- Добавлен диалог подтверждения с названием камеры
- Удаление происходит только после явного подтверждения

### Файлы
- `app/src/main/java/com/example/denmediaipcams/ui/components/CameraEditDialog.kt`
- `app/src/main/java/com/example/denmediaipcams/MainActivity.kt`

3. Убедиться, что фокус меняется быстро (в 4 раза быстрее)

1. Открыть редактирование существующей камеры
2. Проверить наличие красной кнопки "Удалить"
3. Нажать "Удалить" и проверить диалог подтверждения
4. Подтвердить удаление и убедиться, что камера удалена

#### ✅ Тест 4: Показ/скрытие пароля
1. Открыть форму редактирования камеры
2. Ввести пароль
3. Нажать на иконку "глаз" справа от поля пароля
4. Убедиться, что пароль стал виден
5. Снова нажать на иконку
6. Убедиться, что пароль снова скрыт

#### ✅ Тест 5: Автопоиск портов
1. Открыть форму добавления камеры
2. Ввести IP адрес камеры (например, 192.168.1.201)
3. Перейти на вкладку "Порты"
4. Нажать кнопку "Найти доступные порты"
5. Дождаться завершения сканирования (~5 секунд)
6. Убедиться, что найденные порты заполнены в соответствующих полях
7. Проверить, что порты показывают статус доступности

## Риски и ограничения

### Низкий риск
- ✅ Все изменения обратно совместимы
- ✅ Существующие камеры продолжат работать как раньше
- ✅ Добавлена только новая функциональность

### ⚠️ Требует проверки
- ⚠️ Скорость фокуса может быть слишком быстрой для некоторых камер
- ⚠️ Режим MANUAL фокуса может не поддерживаться всеми моделями
- ⚠️ Автопоиск портов проверяет только стандартные порты
- ⚠️ Таймаут 1 секунда на порт может быть недостаточен для медленных сетей

### Известные ограничения
- PTZ функции через HTTP недоступны для камер без HTTP порта (ожидаемое поведение)
- Автофокус может быть отключен после ручной фокусировки (зависит от камеры)
