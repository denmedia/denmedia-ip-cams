✅ ADB доступен: `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`

## Вариант 1: Установка JDK и сборка (рекомендуется)

### Шаг 1: Установка JDK

Скачайте и установите JDK 17 (или новее):
- **Рекомендуется**: [Eclipse Temurin JDK 17](https://adoptium.net/temurin/releases/?version=17)
- Выберите Windows x64 Installer (.msi)
- Установите с настройками по умолчанию

### Шаг 2: Установка переменной окружения

После установки JDK откройте PowerShell и выполните:

```powershell
# Установите JAVA_HOME (замените путь на ваш, если отличается)
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.x.x-hotspot"
[System.Environment]::SetEnvironmentVariable("JAVA_HOME", $env:JAVA_HOME, [System.EnvironmentVariableTarget]::User)

# Проверка
java -version
```

### Шаг 3: Сборка APK

```powershell
cd "D:\MY\Android IP Cam"
.\gradlew.bat assembleDebug
```

Ожидаемое время сборки: 2-5 минут при первом запуске.

### Шаг 4: Установка на устройство

```powershell
& "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

## Вариант 2: Использование Android Studio (если установлен)

### Шаг 1: Открыть проект
1. Запустите Android Studio

1. Build → Build Bundle(s) / APK(s) → Build APK(s)

## После установки: План тестирования

### Тест 1: Камера 192.168.1.201 (проблемная камера)

#### Подключение
1. Запустите приложение на Samsung SM-X916B
2. Добавьте новую камеру
3. IP адрес: `192.168.1.201`
4. Перейдите на вкладку "Порты"
5. **Тест**: Нажмите "Найти доступные порты"
6. **Ожидаемый результат**: 
   - Приложение НЕ вылетает
   - Показывается прогресс сканирования
   - Найденные порты заполняются автоматически

#### Пароль
1. Вернитесь на вкладку "Основные"
2. Введите логин и пароль
3. **Тест**: Нажмите на иконку "глаз" справа от поля пароля
4. **Ожидаемый результат**: Пароль становится видимым

#### Сохранение
1. Нажмите "Сохранить"
2. **Ожидаемый результат**: Камера добавлена без краша

#### Воспроизведение
1. Откройте добавленную камеру
2. **Тест**: RTSP видео должно воспроизводиться
3. **Ожидаемый результат**: Видео показывается, нет вылетов

#### Фокус (если PTZ доступен)
1. Найдите управление фокусом
2. **Тест**: Переместите ползунок фокуса
3. **Ожидаемый результат**:
   - Фокус меняется быстро (~5-6 сек на полный диапазон)
   - Фокус НЕ возвращается автоматически обратно
   - Изменения применяются плавно

### Тест 2: Удаление камеры

1. Нажмите на камеру для редактирования
2. **Тест**: Проверьте наличие красной кнопки "Удалить" внизу диалога
3. Нажмите "Удалить"
4. **Ожидаемый результат**: Появляется диалог подтверждения с названием камеры
5. Нажмите "Отмена"
6. **Ожидаемый результат**: Камера НЕ удалена
7. Снова нажмите "Удалить" → "Удалить" в диалоге
8. **Ожидаемый результат**: Камера удалена

### Тест 3: Автопоиск портов на другой камере

1. Добавьте новую камеру с другим IP (например, `192.168.1.100`)
2. Вручную заполните поле RTSP порт: `554`
3. Оставьте HTTP и ONVIF пустыми
4. Нажмите "Найти доступные порты"
5. **Ожидаемый результат**:
   - RTSP порт остался `554` (не изменился)
   - HTTP и ONVIF заполнены найденными значениями
   - Показано уведомление со списком найденных портов

### Тест 4: Регрессионное тестирование

1. Добавьте камеру со стандартными настройками
2. Проверьте PTZ управление
3. Проверьте переключение потоков (если доступно)
4. **Ожидаемый результат**: Все работает как раньше, без новых проблем

## Известные ограничения

1. **Автопоиск портов**
   - Проверяет только стандартные порты (554, 80, 8080, 81, 8000)
   - Таймаут 1 секунда может быть недостаточен для медленных сетей
   - Не определяет производителя камеры

2. **Фокус**
   - Скорость увеличена в 4 раза - может быть слишком быстро для некоторых камер
   - Режим MANUAL может не поддерживаться всеми моделями

3. **HTTP порт**
   - PTZ через HTTP не работает если порт недоступен
   - Снимки через HTTP не работают если порт недоступен
   - Но RTSP видео работает нормально
